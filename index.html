1. Struktur Dasar, CSS, dan JavaScript

Soal 1a: Mengapa penggunaan CSS dan JavaScript sangat penting dalam pemrograman web modern?

Jawaban: Penggunaan keduanya menciptakan separation of concerns. HTML hanya fokus pada struktur konten, CSS fokus pada presentasi/tampilan visual (layout, warna, font), dan JavaScript fokus pada perilaku/interaktivitas dinamis. Ini membuat kode lebih bersih, mudah dipelihara, dan efisien.

Soal 1b: Sebutkan dan jelaskan dua komponen penting yang harus fleksibel dalam Responsive Web Design (RWD).

Jawaban: Dua komponen penting RWD adalah Fluid Grid (menggunakan unit relatif seperti persen (%) atau `vw` untuk lebar *layout*) dan **Flexible Images** (menggunakan `max-width: 100%` agar gambar tidak melebihi lebar kontainer).

2. Interaktivitas dan Mode Tampilan

Soal 2a: Dalam JavaScript, properti CSS apa yang dimanipulasi untuk menyembunyikan atau menampilkan elemen, seperti yang digunakan pada tugas ini?

Jawaban: Properti CSS yang dimanipulasi adalah `display`. Untuk menyembunyikan, nilainya diubah menjadi `display: none;` (melalui penambahan class `.hidden` menggunakan JS). Untuk menampilkan kembali, class tersebut dihapus atau properti `display` dikembalikan ke nilai aslinya (misalnya `block`, `flex`, atau `grid`).

Saat ini dalam mode: Rapi

3. CSS dan Responsive Web Design (RWD)

Soal 3a: Apa fungsi utama dari Media Queries dalam implementasi RWD?

Jawaban: Media Queries berfungsi untuk menerapkan set aturan CSS tertentu hanya ketika kondisi tertentu terpenuhi, biasanya yang berkaitan dengan karakteristik perangkat seperti lebar layar (`max-width`, `min-width`) atau orientasi perangkat (`orientation: landscape`). Ini memungkinkan layout yang berbeda untuk desktop, tablet, dan smartphone.

Soal 3b: Kapan sebaiknya Anda menggunakan Flexbox dan kapan sebaiknya menggunakan Grid dalam CSS Layout?

Jawaban: Gunakan Flexbox untuk tata letak satu dimensi (mengatur item dalam baris *atau* kolom, misalnya bilah navigasi). Gunakan CSS Grid untuk tata letak dua dimensi (mengatur item dalam baris dan kolom secara bersamaan, ideal untuk struktur utama halaman web atau galeri foto).
